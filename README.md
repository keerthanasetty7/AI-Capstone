# Plantr - AI Plant Disease Prediction Web App

An AI-driven plant disease diagnosis and crop health management web application covering 38 disease and healthy crop classes from the PlantVillage dataset.

## Features
- **38 Crop & Disease Profiles**: Detailed symptoms, causes, organic remedies, chemical treatments, and prevention measures.
- **Interactive Disease Scanner**: Real-time image upload / camera scan with disease classification simulation.
- **Disease & Crop Search / Filter**: Filter by plant species, disease severity, and pathogen type.
- **Responsive Modern UI**: Dynamic styling, dark/light aesthetics, and interactive components.

## Quick Start

Run the application locally with Python:

```bash
python server.py
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
